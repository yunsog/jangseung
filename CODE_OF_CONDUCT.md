# Code of Conduct / 행동 강령

We want Jangseung to be a friendly project for everyone, regardless of background or experience.

**Expected:** be respectful and patient, assume good faith, give and accept constructive feedback, keep discussions technical and on topic.
**Not acceptable:** harassment, personal attacks, discriminatory language, publishing others' private information, trolling.

Maintainers may edit or remove contributions that do not follow this code and may block people who repeatedly break it.
To report a concern, contact the maintainers through a private channel offered by GitHub (for example, a private security advisory or the maintainers' profile contact).

모두가 편안하게 참여할 수 있는 프로젝트를 지향합니다. 존중하고, 선의를 가정하며, 기술적인 이야기에 집중해 주세요. 괴롭힘, 인신공격, 차별 표현, 타인의 개인정보 공개는 허용되지 않습니다.
